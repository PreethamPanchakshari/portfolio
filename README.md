## 🌐 Deploying to Render in 3 Minutes (100% Free & No Spin-Down!)

Because this is a static web application, you can host it as a **Render Static Site**, which has **ZERO cold starts** (it will never spin down or go to sleep!).

### Step 1: Push to GitHub
1. Create a new repository on [GitHub](https://github.com/new) named `portfolio` (or `panchakshari-portfolio`).
2. Upload `index.html` and `README.md` to the repository.

### Step 2: Connect to Render
1. Log in to [Render Dashboard](https://dashboard.render.com/).
2. Click **New +** $\rightarrow$ **Static Site**.
3. Connect your GitHub repository.
4. Fill in the simple settings:
   - **Name:** `panchakshari-portfolio` (or your preferred name)
   - **Branch:** `main`
   - **Build Command:** *(Leave empty)*
   - **Publish Directory:** `.` *(Single dot for root folder)*
5. Click **Create Static Site**.

Render will deploy your site in ~15 seconds and give you a free HTTPS URL (e.g. `https://panchakshari-portfolio.onrender.com`).
